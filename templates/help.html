Password Generator Help

How To Use It

  1. Add a password name, such as amazonMe, from Add New Password Name.
  2. Add an optional comment to identify the account, such as personal Gmail.
  3. Choose the saved password name on the generator page.
  4. Enter your secret key. The key is never saved in MongoDB.
  5. Choose Normal Logic or Enhanced Logic and select Generate.

Normal Logic

Normal Logic combines these values:

  • Password name
  • Secret key
  • Profile Part 1
  • Profile Part 2

The same values produce the same result. However, this older method uses character shifting and is less resistant to analysis. Use Enhanced Logic for real accounts.

Enhanced Logic

Enhanced Logic uses the same core identity values, then applies PBKDF2-SHA256 to make key guessing much more expensive. It also lets you control the password format.

  • Password Length: Number of characters. Use 16 or more when the website allows it.
  • Lowercase: Adds letters from a-z.
  • Uppercase: Adds letters from A-Z.
  • Digits: Adds numbers from 0-9.
  • Symbols: Adds punctuation such as ! @ # $ %. Enable this when the website accepts symbols.
  • Complexity: Changes the arrangement of the generated characters. It does not replace a long password.
  • Counter: Creates a different password for the same account name and key. Increase it if you must change a password.
  • Custom Salt: Adds another personal input to the derivation. Leave it empty unless you have a specific reason to use one.

Important Security Rules

  • Use a long, unique secret key. Do not use a dictionary word, name, birthday, or reused password.
  • Never share your secret key or profile parts.
  • The app stores names and comments, but not generated passwords or secret keys.
  • If you forget the secret key, the app cannot recover the generated password.
  • Use a different password for every website and enable multi-factor authentication where available.
